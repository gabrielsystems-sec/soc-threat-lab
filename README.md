# SOC Operations & Threat Hunting Lab 🛡️

Repositório dedicado ao estudo e implementação de operações de **SOC (Security Operations Center)** utilizando o ecossistema **Wazuh SIEM/XDR**. 

> [!IMPORTANT]
> **Status do Lab:** Em desenvolvimento ativo. Este repositório documenta a transição para a camada de Monitoramento e Resposta a Incidentes (Blue Team).

## 🎯 Objetivos do Laboratório
O foco deste projeto é a centralização de logs, detecção de ameaças em tempo real e resposta automatizada. O laboratório cobre desde a arquitetura do servidor SIEM até o Threat Hunting avançado.

## Roadmap de Implementação
O laboratório está estruturado nas seguintes fases:

- [ ] **Fase 1:** Arquitetura e Deployment do Wazuh Server (Cluster/Single Node).
- [ ] **Fase 2:** Deployment de Agentes e Monitoramento de Endpoints.
- [ ] **Fase 3:** Detecção de Malware e Rootkits.
- [ ] **Fase 4:** Threat Hunting & IDS (Intrusion Detection System).
- [ ] **Fase 5:** Monitoramento de Vulnerabilidades e Auditoria de Compliance.
- [ ] **Fase 6:** Automação de Resposta a Incidentes (Active Response).
- [ ] **Fase 7:** Monitoramento de Cloud e Integração com APIs.

---

## 🛠️ Stack Tecnológica
* **SIEM/XDR:** Wazuh
* **Dashboard:** Wazuh Indexer / Dashboard
* **Logs:** Rsyslog / Filebeat
* **Security Frameworks:** MITRE ATT&CK, NIST.
